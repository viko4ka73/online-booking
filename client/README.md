# Клиент приложения «Играем?»

Основная инструкция запуска и описание возможностей находятся в [README проекта](../README.md).

- `npm ci` — установить зависимости.
- `npm run dev` — запустить сайт локально.
- `npm run lint` — проверить код.
- `npm run build` — проверить типы и собрать сайт в `dist`.

Страницы размещены в `src/pages`, общие блоки — в `src/components`, общие типы и функции — в `src/lib`.
